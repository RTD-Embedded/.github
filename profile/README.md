## Getting Started with RTD

RTD provides manuals on our [website](https://www.rtd.com/#gsc.tab=0) for each product and any software package found here will also include the relevant manuals for the products they support.
Getting started with RTD CPU System on a Module (SoM) require a few 3rd party software packages that aren't provided by RTD. A guide for which packages and manuals to use is found
here on our [CPU Software Guide](https://github.com/RTD-Embedded/RTD-CPU).

There are many different part names that use the same software and manuals. If you're looking for a specific board's software, you can search for it by its shortened name. 
The shortened name will remove all hyphened prefix and suffix letters and will remove the 'HR' from our product names. For example: the `IDAN‑DM35224HR‑62S` is a data module 
called the `DM35224`. You can search for the relevant software, by clicking repositories and searching for `DM35224`. You will notice that the repository that is found may 
not be the same name as the one your searched in this case [DM35424-Linux](https://github.com/RTD-Embedded/DM35424-Linux). There may also be more than one repository. Check 
under the repository's `readme.md` to confirm if your board is supported.
